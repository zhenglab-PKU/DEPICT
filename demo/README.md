### Demo

Demo notebooks are provided to illustrate the application of DEPICT to spatial transcriptomics and single-cell RNA-sequencing data:

* **`Spatial_demo_P7-2_LUAD.ipynb`** — Demo for applying DEPICT to **spatial transcriptomics data** from a lung adenocarcinoma (LUAD) sample.
* **`scRNAseq_demo_A375.ipynb`** — Demo for applying DEPICT to **single-cell RNA-sequencing data** from an A375 cell line-derived dataset.
